# BLACKNODE
BLACKNODE is a terminal-based hacking simulation game written in Python.

This project was created for learning purposes and to practice object-oriented programming concepts.

## Features
- Object-oriented architecture
- User authentication system
- Secure servers
- Protected files
- Save and load system
- Failed loginprotection
- Server locking system
- Polymorphism and inheritance

## Commands
- help
- scan
- connect <ip>
- login <username> <password>
- ls
- cat <file>
- save <name>
- load <name>
- status
- exit

## Technologies
- Python
- JSON
- OOP
